# 💰 Baztami – Application de Gestion de Budget

Baztami est une **application web** permettant à chaque utilisateur d’ajouter, suivre et organiser facilement ses **revenus** et **dépenses**, avec un affichage clair du **solde total en temps réel**.  
Les données sont **enregistrées automatiquement** dans le navigateur via `localStorage`.

---

## 🎯 Objectif
Faciliter la maîtrise du budget quotidien :
- Ajouter, modifier et supprimer les transactions 💵  
- Visualiser les totaux (revenus, dépenses, solde) 💰  
- Conserver les données localement 💾  

---

## 👥 User Stories

- 💳 Ajouter une transaction (description, montant, type, date)  
- 💶 Afficher les transactions sous forme de cartes colorées :  
  🟩 vert pour revenu, 🟥 rouge pour dépense  
- ✏️ Modifier une transaction existante  
- 🗑️ Supprimer une transaction avec confirmation  
- 💰 Calculer en temps réel le total des revenus, dépenses et solde net  
- 🏦 Sauvegarder automatiquement les données dans `localStorage`
